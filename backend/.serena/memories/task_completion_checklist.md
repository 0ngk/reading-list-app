# Task Completion Checklist

When completing a task, ensure the following:

1. **Run Tests**
   ```bash
   pnpm test
   ```

2. **Run Linting**
   ```bash
   pnpm lint
   ```

3. **Build Check**
   ```bash
   pnpm build
   ```

4. **Format Code** (if needed)
   ```bash
   pnpm format
   ```

## Commit Message Format
Use conventional commits:
- `feat:` - New feature
- `fix:` - Bug fix
- `refactor:` - Code refactoring
- `docs:` - Documentation
- `test:` - Tests
- `chore:` - Maintenance
